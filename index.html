SciPTC Upload

A personal research data utility · rclone + Google Drive API

SciPTC Upload is a personal research data management utility powered by rclone and the Google Drive API. It is used by its owner to upload, organize, and verify scientific research archives in their authorized Google Drive account.

This website only describes that personal tool. It does not host the tool, and it does not offer any service to the public.

What it does

  • Packages locally generated scientific research output into ZIP archives.
  • Uploads those archives to the owner’s own Google Drive using the Google Drive API.
  • Verifies that uploaded files exist and match the expected size.
  • Organizes archives into dated folders and records their file identifiers.

Who uses it

One person: the owner of the tool and of the Google Drive account it writes to. There is no sign-up, no user accounts, and no multi-tenant access.

How Google Drive is used

The tool requests the Google Drive scope so that it can create folders, upload archives, list files, read file metadata, and remove or replace objects that the owner explicitly asks it to manage. It operates only inside the owner’s own Drive.

Data handling

OAuth credentials are stored only on machines controlled by the owner. This website is static: it collects nothing, sets no cookies, and loads no third-party scripts, fonts, or analytics.
