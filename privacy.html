Privacy Policy

SciPTC Upload · Last updated: 12 November 2026

SciPTC Upload is a personal utility operated by a single individual for their own research data management. It is not a public service, and it has no user registration of any kind.

1. Who this applies to

There is exactly one user: the owner of the tool and of the Google account that authorises it. No other person can sign in, create an account, or use this tool.

2. What the tool does with Google Drive

The tool is authorised with the Google Drive scope (full Drive access). It uses that authorisation to:

  • create and manage folders inside the owner’s own Drive;
  • upload ZIP archives of scientific research output;
  • list files and read file metadata such as name, size, and modification time;
  • verify that an uploaded file exists and matches the expected size;
  • move, rename, or delete objects only when the owner explicitly asks it to.

The full Drive scope is requested because rclone’s Google Drive backend operates on the whole Drive: folder creation, listing, and file moves all require it. This policy does not claim narrower access than the tool actually holds. The tool is operated only against the owner’s own Drive and is not pointed at anybody else’s account.

3. What this website collects

Nothing. This site is a set of static HTML pages. It sets no cookies, runs no analytics, loads no third-party scripts, fonts, or images, and has no forms or comment systems.

4. Where credentials are stored

OAuth client credentials and refresh tokens are stored only in the rclone configuration on machines controlled by the owner. They are never sent to, embedded in, or served by this website. This site contains no tokens, keys, or configuration files.

5. What happens to the research files

Research archives are uploaded from the owner’s own systems to the owner’s own Google Drive. They are not sold, published, or transferred to any other third party by this tool. Google’s handling of data stored in Drive is governed by Google’s own terms and privacy policy.

6. Third parties

The tool talks to two external services only: the Google Drive API, to store the owner’s own files, and (optionally) GitHub, to host these static pages. No advertising, profiling, or data-broker service is involved.

7. Retention and deletion

Archives remain in the owner’s Drive until the owner deletes them. Deleting a file in Drive removes it from the account; the tool keeps no separate copy of Drive contents.

8. Revoking access

The owner can revoke this application’s access at any time from the Google Account permissions page (myaccount.google.com/permissions). Revocation immediately invalidates the stored refresh token, and the tool stops working until it is authorised again.

9. Children

This tool is not directed at children and is not offered to the public, so it does not knowingly collect information from anyone, including children.

10. Changes

If this policy changes, the updated version will be posted on this page with a new “last updated” date.

11. Contact

For any question about this policy, contact the owner through the GitHub account that hosts this site: github.com.
